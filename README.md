# RoofSprout (ছাদবাগান সহকারী) — Android

এই প্রজেক্ট থেকে GitHub Actions দিয়ে আপনি নিজেই APK বানাতে পারবেন। নিজের কম্পিউটারে Android Studio লাগবে না।

## APK বানানোর ধাপ

1. GitHub-এ নতুন একটি repository খুলুন (যেমন `roofsprout`)। Private রাখতে পারেন।
2. এই ZIP-এর **ভেতরের সব ফাইল ও ফোল্ডার** (`www`, `assets`, `scripts`, `.github`, `package.json`, `capacitor.config.json`, `.gitignore`) repository-তে আপলোড করুন।
   - ওয়েবসাইটে "Add file → Upload files" দিয়ে আপলোড করলে `.github` ফোল্ডার কখনো কখনো বাদ পড়ে। বাদ পড়লে "Add file → Create new file" চেপে নাম দিন `.github/workflows/build-apk.yml` এবং ফাইলের লেখা পেস্ট করুন।
   - অথবা git দিয়ে: `git init`, `git add .`, `git commit -m "first"`, `git branch -M main`, `git remote add origin <repo-url>`, `git push -u origin main`
3. repository-র **Actions** ট্যাবে যান। "Build Android APK" নামে কাজ নিজে চলতে শুরু করবে (না চললে বাঁয়ে ওই নামে চাপুন, তারপর "Run workflow")।
4. ৫-১০ মিনিট পর কাজ সবুজ টিক পেলে ভেতরে ঢুকুন। নিচে **Artifacts** অংশে `roofsprout-debug-apk` পাবেন। ডাউনলোড করে ZIP খুললে `app-debug.apk`।
5. ফোনে APK পাঠান, খুলে ইনস্টল করুন। প্রথমবার "অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হতে পারে।

## অ্যাপ চালানোর পর

অ্যাপ খুলে উপরে ডানের **সেটিং** আইকনে চাপুন:

- **নোটিফিকেশন:** সময় বেছে "নোটিফিকেশন চালু করুন" চাপুন, অনুমতি দিন। রোজ বাগান দেখা আর প্রতিটা গাছের পানির সময়ে ফোনে মনে করাবে।
- **এআই কী:** ছবি দেখে রোগ চেনা, সাজেশন, সাপ্তাহিক রিপোর্ট, নতুন গাছ যোগ করা, গাছের ছবি স্ক্যান, এগুলোর জন্য আপনার নিজের Anthropic API কী লাগবে (console.anthropic.com থেকে)। কী শুধু ফোনে থাকে, কোডে বসানো নেই। ব্যবহারের খরচ আপনার অ্যাকাউন্ট থেকে যায়।
- **লাইভ আবহাওয়া:** ঢাকার আবহাওয়া ইন্টারনেট থেকে নিজে আসে (Open-Meteo, কোনো কী লাগে না)।

## জেনে রাখুন

- এই APK **debug** ধরনের। নিজের ফোনে বা বন্ধুদের দিয়ে চালানো যায়, কিন্তু Google Play-তে দেওয়া যায় না। Play Store-এর জন্য signed release বানাতে হবে।
- ফন্ট (Hind Siliguri) ইন্টারনেট থেকে নামে। অফলাইনে ফোনের নিজের বাংলা ফন্টে দেখাবে।
- আবহাওয়া এখন শুধু ঢাকার জন্য।
- নোটিফিকেশন নতুন করে সাজানো হয় প্রতিবার তথ্য সেভ হলে। কোনো ফোনের ব্যাটারি সেভার অ্যাপ বন্ধ রাখলে নোটিফিকেশন দেরিতে আসতে পারে। সেক্ষেত্রে ফোনের সেটিংসে RoofSprout-কে "unrestricted" করুন।
- API কী কারও সাথে শেয়ার করবেন না।

## কোড বদলাতে চাইলে

পুরো অ্যাপ `www/index.html` ফাইলে। বদলে আবার push করলেই GitHub নতুন APK বানাবে।
